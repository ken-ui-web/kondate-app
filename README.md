# こんだて帖 🍚

毎晩の献立をおまかせで決めてくれるWebアプリです。

## できること

- 📅 **ひと月分の晩ごはんを自動生成** — 同じ料理が2週間以内に重ならないよう、和洋中・肉魚のバランスをとって抽選します。気に入らない日は個別に引き直し可能。
- 🛒 **今週末の買い物リスト** — 翌週（土〜金）の献立の材料を人数分に換算して自動集計。冷蔵庫の在庫と常備調味料は除外されます。
- 🧊 **冷蔵庫から提案** — いま冷蔵庫にある食材を登録すると、それを多く使えるレシピをマッチ率順に提案します。
- 📖 **レシピ管理** — 定番おかず約50品を内蔵。自分の家の料理も追加・編集できます。
- 📱 **PWA対応** — スマホの「ホーム画面に追加」でアプリのように使えます。

## 技術

- Vite + React + TypeScript
- データはブラウザの localStorage に保存（サーバー不要）
- GitHub Pages でホスティング

## 開発

```bash
npm install
npm run dev
```

## データについて

献立・レシピ・冷蔵庫のデータは使っている端末のブラウザ内に保存されます。
設定画面からJSONファイルとしてバックアップ・復元ができます。

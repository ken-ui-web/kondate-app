# 献立管理アプリ 🍚

2週間分の晩ごはんの献立を書きとめて、使いたい食材からレシピを探せるWebアプリです。

## できること

- 📅 **こんだて** — 今日から2週間分の献立を、1日ごとに「メインのおかず・副菜・汁物」の3品まで自由に入力できます。「＋」を押して入力し、変えたいときはもう一度押せば書き換えられます。入力内容はこの端末に自動保存されます。
- 🔎 **レシピ** — 使いたい食材（いくつでも）と料理の種類（メイン・副菜・汁物）を選んで検索すると、AI（Google Gemini）がレシピサイトを検索してレシピ案を出典リンク付きで表示します。クックパッド・クラシル・DELISH KITCHEN・楽天レシピ・Nadia で直接検索するボタンもあります（こちらはAPIキー不要）。
- 📱 **PWA対応** — スマホの「ホーム画面に追加」でアプリのように使えます。

## AI検索について

AIによるレシピ検索には、ご自身の Google AI Studio（Gemini）の APIキーが必要です。レシピ画面の「AI検索の設定」に貼り付けてください。キーは使っている端末のブラウザ内にだけ保存されます。

## 技術

- Vite + React + TypeScript
- データはブラウザの localStorage に保存（サーバー不要）
- GitHub Pages でホスティング

## 開発

```bash
npm install
npm run dev
```
